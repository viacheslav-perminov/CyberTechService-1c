# КиберТехСервис — конфигурация 1С:Предприятие 8.3

Учебный проект автоматизации сервисного центра по ремонту компьютерной техники.

**Цель проекта:** разработать с нуля конфигурацию 1С, обеспечивающую учёт заказов на ремонт, складских операций, оплат клиентов и финансовых результатов.

## Реализованные возможности

- Ведение справочников клиентов, сотрудников, оборудования, видов работ, номенклатуры, складов и поставщиков.
- Регистрация заказов на ремонт с учётом статусов выполнения.
- Добавление работ и материалов с автоматическим расчётом стоимости.
- Контроль складских остатков и списание материалов при проведении заказов.
- Учёт поступления товаров и расчёт себестоимости материалов.
- Регистрация оплат клиентов и контроль задолженности.
- Формирование печатных форм «Заказ-наряд» и «Акт выполненных работ».
- Разграничение прав доступа по ролям.

## Отчёты

1. Ведомость остатков товаров.
2. Задолженность клиентов.
3. Прибыль по ремонтам.
4. Поступления денежных средств.

## Использованные технологии

- Платформа 1С:Предприятие 8.3.
- Управляемые формы.
- Встроенный язык 1С.
- Справочники и документы.
- Регистры накопления.
- Язык запросов 1С.
- Система компоновки данных (СКД).
- Табличные документы и макеты печатных форм.
- Роли и права доступа.

## Структура проекта

`ServiceCenter.cf` — файл конфигурации.

`ServiceCenter_Demo.dt` — демонстрационная информационная база с тестовыми данными.

`screenshots/` — скриншоты основных возможностей программы.

## Назначение

Проект создан для практического освоения разработки на платформе 1С:Предприятие 8.3 и демонстрации навыков при трудоустройстве на позицию Junior 1С-разработчика.
